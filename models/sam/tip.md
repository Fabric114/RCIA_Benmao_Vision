# SAM checkpoint

This project does not commit the public SAM checkpoint file.

Download the ViT-B checkpoint from the official Segment Anything release:

- Official repository: https://github.com/facebookresearch/segment-anything
- ViT-B checkpoint: https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth

Expected local path:

```text
models/sam/sam_vit_b_01ec64.pth
```

You can also run:

```bash
bash scripts/download_public_weights.sh
```
